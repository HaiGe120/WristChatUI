WristChatUI — Support

AI chat for iPhone and Apple Watch, with your choice of compatible connection and optional web search.

Contact

For a connection problem, include the app version, device/OS, API format, model, whether Search is on, and the visible error. Do not include API keys, bearer tokens, private chat content or unredacted configuration files.

Set up chat

On iPhone, open Settings → Endpoints and add the base URL, API format, model and any required key. Supported formats are OpenAI Responses, OpenAI Chat Completions and Anthropic Messages. Compatibility depends on the server's actual implementation. The app does not supply an AI subscription or include ChatGPT subscription sign-in.

Use web search

Search defaults to Off. Enable Web search inside a chat. With Native selected, a supported model decides when to use its server-side search tool. A compatible chat API does not automatically imply search support; availability also depends on the model and account.

To use a separate source, open Settings → Search sources. MiniMax plan search uses an explicitly entered key for the selected region and requires the relevant entitlement. A custom MCP source needs a remotely reachable HTTPS Streamable HTTP server, one selected search tool, its question field and any required fixed arguments. Bearer tokens and custom API-header credentials are supported. Desktop command/stdio configurations need a separately hosted HTTP bridge. Interactive MCP OAuth and arbitrary client actions are outside the supported search subset.

The selected source receives your question and the chat model receives its returned references. Search status distinguishes ordinary answers, reference-only material, successful search and failures. Source details contain returned links rather than links invented by the app.

Connection failures and Retry

Stop cancels the active attempt. After a timeout or interrupted reply, Retry reuses the original question and replaces that interrupted response. Sending a new message creates a separate turn. Useful partial text remains labeled; a disconnected stream is not marked complete. No ambiguous timed-out generation is automatically resent.

If a native search tool is explicitly unsupported, select another configured source or turn Search off. Recheck native search in the connection editor after changing the server, model or account capabilities. A network timeout or usage limit is not evidence that search is unsupported.

Apple Watch networking

The Watch app uses watchOS networking for its requests. A nearby iPhone, working sync and a working iPhone VPN do not establish the network route or VPN rules used by a Watch request. The app does not provide a foreground iPhone chat relay.

For comparison, use the same endpoint, API format and model on both devices, with Search off for one test. Note the Watch connection icon and inspect your VPN client's connection log for the endpoint hostname, matched rule and outbound. A missing log entry is a clue, not a confirmed cause. Connection help is available on Watch beside network errors and in Endpoints. Do not remove your library or credentials to diagnose a timeout.

Data, sync and backups

Chat keys use Keychain, search credentials use a separate Keychain service, and conversations are stored locally. Profiles, credentials and chats sync to the paired device. Optional iCloud backups include messages and compact source details but not credentials from secure key fields. Deleting a chat does not erase older backup copies. See the Privacy Policy.

GitHub release files

Read the signing and installation notes for each release asset. An App Store distribution IPA is not directly installable by downloading it. Development/ad hoc packages require suitable signing and device registration. The iPhone package contains its matching Watch app.
