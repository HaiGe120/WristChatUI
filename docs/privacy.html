WristChatUI — Privacy Policy

Last updated: November 2, 2026

WristChatUI is a bring-your-own-connection AI chat app for iPhone and Apple Watch. This page describes the data handled by the WristChatUI project and the services you choose to use.

Developer-operated services

WristChatUI does not operate a chat or search backend, an advertising service, or a usage analytics service. The app does not include a developer-operated analytics or crash-reporting SDK. Apple may handle App Store and operating-system diagnostics according to your device settings and Apple's policies.

Data stored on your devices

  • Chat API keys entered in the secure key field are stored in Keychain.
  • Independent search credentials entered in the secure field are stored in a separate Keychain service and bound to the configured search destination.
  • Conversations, replies, request outcomes, source URLs and compact citation details are stored in a local database.
  • Connection and search profiles, model choices, system prompts and other preferences are stored locally. Use the dedicated credential fields rather than putting secrets in names, URLs or fixed search arguments.

Chat requests

When you send a question, your selected chat endpoint receives the question, the conversation context needed to answer, the system prompt and its configured authentication. You choose that endpoint and model. The provider or gateway applies its own privacy policy, retention practices and usage limits.

Web search and source links

Search is off by default. Native search is performed by your selected chat service when its endpoint, model and account support it. That service determines how its search tool handles the query.

If you explicitly select a separate MiniMax plan search or custom remote MCP source, that source receives the search question and its own configured credential. Retrieved reference material is then sent to your selected chat model so it can answer. These are separate destinations, with their own privacy policies and account requirements. Chat credentials are not automatically reused for an unrelated search service.

Search-backed replies can retain returned source URLs, titles and compact excerpts. Full retrieved search documents are not stored as separate conversation records or included as raw documents in conversation backups. A generated answer may itself quote or summarize reference material.

Opening a source link contacts that website through the system's link-opening service. The website may receive information such as your IP address under its own policies.

Paired Apple Watch

Connection profiles, chat keys, conversations and compact source metadata sync between your iPhone and paired Apple Watch using Apple's paired-device communication. Search profiles and credentials are provisioned through a separate path, with the credentials stored in Watch Keychain. The Watch app can then request the configured services using watchOS networking. The app does not operate a developer-hosted relay.

Apple system features

Dictation, Siri Shortcuts and system link-opening features use Apple's system services. Their handling of voice input and related information is governed by your device settings and Apple's policies.

Optional iPhone voice input uses microphone access and Apple's speech recognition service. Depending on your language and device, audio may be processed by Apple. The app does not save raw microphone recordings or include them in conversation backups. The recognized text is stored as an ordinary chat message and sent to your selected chat connection, and to a separately selected search source when search is enabled. Apple Watch uses Apple's system dictation screen. CarPlay is not enabled in the current distribution.

Spoken replies use Apple's speech synthesis. Automatic playback is off by default on iPhone and Watch and is controlled separately on each device. Incoming synced conversation history does not trigger playback. Speech language and speed preferences remain local to each device.

Optional iCloud backups

If you choose Back Up to iCloud, the app writes conversation JSON to your iCloud Drive container. These backups include messages, compact source details and request outcomes. Credentials entered through the secure key fields are not included. iCloud storage and account handling are governed by Apple's policies. Backups already saved to iCloud remain until you remove them through iCloud Drive or Apple's storage controls.

Your controls

  • Choose destinations: configure or remove chat connections and independent search sources. Turn Web search off to send an ordinary request without the app's optional search step.
  • Remove credentials: deleting a chat endpoint or search source removes its app-managed Keychain credential on that device and updates paired-device configuration when sync is available. Provider-side revocation is managed with the provider.
  • Delete chats: delete whole conversations in the app. Deletion is sent to the paired device when communication is available. Copies in previously created backups are separate and must be managed separately.
  • Export and restore: use the optional conversation backup and restore controls.
  • Uninstall: removing the app removes its app-container data. Keychain entries and iCloud backups can persist; uninstalling is not a substitute for deleting or revoking credentials and removing backups.
